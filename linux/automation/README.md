# Linux - Automation

Bash scripts for system administration on the Fortress Ubuntu node.

## Scripts (Planned)

| Script | Purpose |
|---|---|
| `system-update.sh` | Automated security updates with pre/post log to MySQL |
| `backup-mysql.sh` | Encrypted MySQL dump to Azure Blob Storage |
| `audit-users.sh` | Review local accounts, sudo access, authorized SSH keys |
| `check-services.sh` | Verify only approved services running, alert on deviations |
