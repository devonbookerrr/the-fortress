# Identity - Entra ID Configuration

Tenant-level Entra ID settings for The Fortress.

## Configuration Areas

- **Authentication Methods** - FIDO2 and Microsoft Authenticator only. SMS and voice disabled.
- **User Settings** - App registrations restricted to admins. External collaboration blocked.
- **Enterprise Apps** - User consent blocked. Admin consent workflow enabled.
- **Identity Protection** - User risk and sign-in risk policies enforcing password change + MFA on remediation.
- **Access Reviews** - Quarterly reviews on all privileged roles and guest accounts.
