# M365 - Defender for Office 365 P2

Defender for Office 365 policy configuration.

## Policies

| Policy | Settings | Status |
|--------|---------|--------|
| Safe Links | Enabled for email and Teams, real-time URL scanning, no bypass | Planned |
| Safe Attachments | Dynamic Delivery, quarantine malicious attachments | Planned |
| Anti-Phishing | Mailbox intelligence, impersonation protection for all domains and senders | Planned |
| Attack Simulator | Monthly phishing simulation targeting all users | Planned |

## Deployment

Policies are configured via the Microsoft 365 Defender portal or the Security and Compliance PowerShell module.
